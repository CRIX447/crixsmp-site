# Rank icons (optional)

Small square icons shown next to each rank name in the ranks table, best at **64 × 64** (a see-through PNG looks best). Leave any out and that rank just shows its name.

| File name | Rank |
|---|---|
| `member.png` | Member |
| `vip.png` | VIP |
| `vip-plus.png` | VIP+ |
| `mvp.png` | MVP |
| `mvp-plus.png` | MVP+ |
| `elite.png` | ELITE |
| `crix-plus.png` | CRIX+ |

Upload with **Add file → Upload files**, then **Commit changes**.
