# Pictures

Upload pictures with **Add file → Upload files**, then **Commit changes**. Vercel puts them live about a minute later.

`.png`, `.jpg`, `.jpeg`, `.webp` and `.gif` all work, and capital letters don't matter. Anything you haven't added yet keeps the built-in artwork, so add them in any order.

## This folder

| File name | Where it shows | Best size |
|---|---|---|
| `logo.png` | Top bar and footer. A see-through PNG looks best. | 512 × 512 |
| `hero.png` | The big picture behind "CRIX SMP" at the top (replaces the moving pixel hills) | 1920 × 1080 |
| `banner.png` | The preview picture when the link is posted on Discord and other apps. **Must be .png.** | 1200 × 630 |
| `favicon.png` | Browser tab icon. Optional: the logo is used if it's missing. | 64 × 64 |

## See where each picture goes

Open the site with `#images` on the end: **https://crixsmp.vercel.app/#images**. Every picture spot shows the file it wants, and turns green once it's found. The "Site setup" box at the bottom counts what you've added.

## Screenshot tips

- Hide the HUD first: pause, then **Settings → Video → Hide HUD**.
- Wide landscape shots (16:9) suit the hero, the feature cards and the banner.
- If a picture doesn't show, check the name for a double ending like `spawn.png.png`. Windows hides endings unless you turn on **View → Show → File name extensions** in File Explorer.
