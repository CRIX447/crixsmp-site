# Pictures for the CRIX SMP website

Upload pictures here: **Add file → Upload files**, drop them in, then **Commit changes**. Vercel puts them live about a minute later.

Name them exactly as below, all lowercase. `.png`, `.jpg`, `.jpeg` and `.webp` all work (`spawn.png` or `spawn.jpg`), except `banner.png`, which must be a PNG. Anything you haven't added yet shows built-in artwork, so add them in any order.

## Check where each picture goes

Open the site with `#images` on the end: **https://crixsmp.vercel.app/#images**. Every picture spot shows the file name it wants, with a green tick once it's found. Visitors never see this unless they add `#images` themselves.

## If a picture doesn't show

- **Check the exact name.** The website is case sensitive: `Spawn.png` won't work, `spawn.png` will.
- **Check for a double ending.** Windows hides file endings, so a file can end up called `spawn.png.png`. In File Explorer turn on **View → Show → File name extensions** to see the real name.
- **Wait a minute and refresh.** Vercel needs about a minute after each commit.

## Screenshot tips

- Hide the HUD first: pause, then **Settings → Video → Hide HUD**.
- Wide landscape shots (16:9) suit the hero, the feature cards and the banner.
