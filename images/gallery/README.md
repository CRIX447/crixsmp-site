# Screenshots

Put as many screenshots here as you like, **with any names**. The Screenshots section appears on the site as soon as there's one.

- They show in name order, so start names with numbers if you want a set order: `01 Spawn.png`, `02 Crates.png`…
- The file name becomes the caption: `Spawn at night.png` shows "Spawn at night". Plain numbers like `3.png` get no caption.
- Visitors can click a screenshot to see it big and use the arrow keys to flip through.
- Any size works. Landscape shots look best.

Upload with **Add file → Upload files**, then **Commit changes**.
