# Crate pictures

Square pictures, best at **800 × 800**. Any of `.png`, `.jpg`, `.webp` or `.gif`.

| File name | Crate |
|---|---|
| `common.png` | Common Crate |
| `gold.png` | Gold Crate |
| `amethyst.png` | Amethyst Crate |
| `prime.png` | Prime Crate |
| `crimson.png` | Crimson Crate (the big one at the bottom) |

Upload with **Add file → Upload files**, then **Commit changes**.
