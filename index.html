About the server

What CRIX SMP is

A survival server built around the people playing on it. No application form, no hoops — grab the IP, read the rules, and you're in.

Survival

Straight survival multiplayer

Everyone starts the same way and builds up from there. Gather, farm, mine, fight things, settle somewhere that suits you.

Crossplay

Java and Bedrock, one world

Whatever edition you own, you're on the same map as everyone else, using the same address.
