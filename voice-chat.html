How to join

CRIX S.M.P runs Java and Bedrock together. Pick whichever edition you own. Both use the same address and land in the same world.

Server address play.crixsmp.net

Java Edition

PC
  1. Open Minecraft Java Edition.
  2. Select Multiplayer.
  3. Select Add Server.
  4. Enter the server address below. The name field is just a label, call it CRIX S.M.P.
  5. Select Done to save it.
  6. Select CRIX S.M.P in the list and connect.
Server address play.crixsmp.net

Bedrock Edition

Console / Mobile / Win
  1. Open Minecraft Bedrock Edition.
  2. Select Play, then the Servers tab.
  3. Scroll down and select Add Server.
  4. Enter a name, then the address and port below.
  5. Save, then select CRIX S.M.P and join.
Server address play.crixsmp.net
Port 19132

Some consoles restrict adding custom servers. If your platform won't let you add one directly, ask in Discord and we'll point you at the setup for it.

Troubleshooting

Work down this list. It's almost always one of these.

The server shows as offline

Check the live status panel on the homepage. If it says offline there too, the server really is down, usually a restart or maintenance. Give it a few minutes and check Discord for an announcement.

I can't connect but the server is online

Run through these in order:

  • Retype the address by hand. A stray space or typo is the usual culprit.
  • Delete the saved server entry and add it again from scratch.
  • Fully close Minecraft and your launcher, then reopen.
  • Restart your router if nothing else worked.
It says my version is wrong or unsupported

Your client version has to match what the server is running. Switch your launcher profile to that version and try again. Ask in Discord if you're not sure which one to pick.

Java and Bedrock connect differently

Java uses the address on its own. Bedrock needs the address and the port field filled in. Leaving the port blank is the most common reason a Bedrock connection fails. Both editions end up in the same world.

Connection drops, lag spikes or timeouts

Try a wired connection or move closer to your router, and close anything else eating bandwidth. VPNs, school and work networks often block game traffic. If you're on one, that's likely the problem.

Still stuck?

Ask in Discord. Someone's usually around and it's the fastest way to sort it out.
