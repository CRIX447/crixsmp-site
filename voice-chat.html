Simple Voice Chat

Simple Voice Chat adds proximity voice chat to Minecraft, so players near each other in-game can talk using voice. Walk up to someone and you hear them. Walk away and they fade out.

i

This is a Java Edition mod and it's optional. You can play on CRIX SMP without it. Only download it from the official sources below. Reuploads on random download sites are how people end up with malware.

Installing it

Java Edition
  1. Check the server's Minecraft version. The status panel on the homepage shows what CRIX SMP is running. Everything you download has to match it.
  2. Install a mod loader. Fabric, Forge or NeoForge, whichever the mod supports for that version.
  3. Download the matching Simple Voice Chat file. Filter by your Minecraft version and loader before grabbing a file. On Fabric you also need Fabric API.
  4. Put the .jar in your mods folder. Windows %appdata%\.minecraft\mods, macOS ~/Library/Application Support/minecraft/mods, Linux ~/.minecraft/mods. Create the folder if it isn't there.
  5. Launch the modded profile in your launcher, not vanilla.
  6. Join CRIX SMP at play.crixsmp.net.
  7. Set your keybind and microphone. Open voice chat settings from the in-game icon, pick your mic, choose push to talk or voice activation, and test it there.

What you need

CLIENT SIDE

Minecraft Java Edition, a supported mod loader, and the mod in your mods folder. That's the whole client setup.

SERVER SIDE

Voice chat only works if the server runs Simple Voice Chat too. If the game says the server doesn't have voice chat, check Discord before assuming your install is broken.

BEDROCK

It's a Java Edition mod, so Bedrock players can't install it. You can still play normally and use Discord voice.

VERSIONS

Minecraft version, loader version and mod version all have to line up. Most problems come down to one of the three being wrong.

Troubleshooting

My microphone isn't detected

Open voice chat settings in-game and select your microphone from the device list. It often defaults to the wrong device. If nothing shows up, check your OS lets apps use the microphone (Windows: Settings, Privacy, Microphone / macOS: System Settings, Privacy and Security, Microphone), then restart Minecraft.

It says voice chat isn't connected

The voice connection couldn't be established. Rejoin the server, and if it keeps happening check whether a firewall, VPN or restricted network is blocking it. Report it in Discord if it persists, it may be server side.

Mod version mismatch

Minecraft will refuse to load or disconnect you with a version message. Delete the file you downloaded, confirm the server's Minecraft version, and download the build matching both that version and your loader.

The voice chat icon doesn't appear

Nine times out of ten the mod isn't loading. Check you launched the modded profile rather than vanilla, that the .jar is directly in mods and not a subfolder, and on Fabric that Fabric API is installed too.

Nobody can hear you

Check each of these:

  • You aren't muted in the voice chat settings.
  • You're holding push to talk, or voice activation is on.
  • Your mic volume isn't at zero in Minecraft or your OS.
  • The other person is close enough, it's proximity based.
  • They have the mod installed as well.

Can't get it working?

Ask in Discord and someone will walk you through it.
